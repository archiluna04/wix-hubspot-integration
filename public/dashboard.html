      Form attribution in HubSpot

      When a visitor submits a Wix form, the contact is created or updated in HubSpot within seconds. Attribution is stored in the HubSpot property group Wix Integration:

      • wix_original_utm_*, wix_original_landing_page, wix_original_referrer: first touch, never overwritten
      • wix_latest_utm_*: UTM parameters of the most recent visit
      • wix_last_form_name, wix_last_form_page_url, wix_last_form_referrer, wix_last_form_submitted_at

      UTM parameters are captured automatically by the site script. You can also add hidden form fields named utm_source, utm_medium, utm_campaign, utm_term and utm_content. To send a custom form field to an existing HubSpot property, set the field's key to the property's internal name (for example jobtitle).
